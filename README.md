# WebFolio

Multi-page portfolio / agency website. Static HTML + CSS + vanilla JS — no database, deploys anywhere (GitHub Pages, Netlify, Vercel).

The published site is [https://prathamkumar.me/](https://prathamkumar.me/).

## Structure
```
├─ build.py                 ← edit content/layout here, then run: python build.py
├─ *.html                   ← generated pages (committed so hosting needs no build)
├─ assets/
│  ├─ css/styles.css        ← design system (colors/spacing in :root)
│  ├─ js/main.js              ← nav, theme, reveal, counters, form, testimonials
│  ├─ data/testimonials.json← add real client quotes here (section auto-shows)
│  ├─ img/og-image.png      ← social share image
│  └─ logo/webfolio-mark.svg
├─ _internal/               ← notes not published (Jekyll ignores `_` folders)
├─ sitemap.xml, robots.txt  ← regenerated by build.py
```

## Pages
Home · Services (+ Website / Android / Maintenance landing pages) · Work · Pricing · About · Careers · FAQ · Contact · Free tools · Privacy · Terms · Thank-you · 404.
Retired URLs (`hire`, `dedication`, `process`, `showcase`, `testimonials`, `performance`, `release-checklist`, `changelog`) redirect to their new homes.

## Edit workflow
1. Change text/sections in `build.py` (shared header, footer and SEO tags are defined once).
2. `python build.py`
3. Preview: `python -m http.server 5500` → http://localhost:5500

The site follows the visitor's system light/dark preference by default. The theme
button can override that preference and stores the choice in the browser.

The Careers page at `careers.html` has a separate student application form with
role selection, education details, portfolio/GitHub URL, message and a required
PDF/DOC/DOCX resume upload (limited to 5 MB). Applications are sent through
FormSubmit to the configured project email, then the page shows an inline
“Application received” confirmation instead of relying on a separate redirect page.

## SEO and launch checklist
1. Confirm `BASE` in `build.py` matches the final domain.
2. If analytics are required, replace `GA_ID` in `build.py` with a real GA4 ID.
   The placeholder ID is intentionally not emitted into pages.
3. Submit the form once and approve the FormSubmit confirmation email.
4. Add real testimonials to `assets/data/testimonials.json`:
   `[{"name":"…","role":"…","rating":5,"quote":"…"}]`
5. Verify the claims in the content (team size, case-study numbers, "30+ projects" etc.).
6. In Google Search Console, verify the property, submit `sitemap.xml`, and inspect
   the homepage and important service pages. Search Console is the source of truth
   for indexing, queries, clicks, impressions, and average position; public searches
   vary by location, device, personalization, and index freshness.
